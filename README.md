**Note-Taking & Journaling App** · `Mobile`

Simple and elegant note-taking application with rich text editing, search, and cloud sync.

## Features

- Create, edit, and delete notes
- Search through notes
- Color-coded note cards
- User authentication with email/password
- Clean, minimal Material Design UI

## Tech Stack

- Flutter
- Dart
- Firebase Auth
- Cloud Firestore

## About

A lightweight journaling app built with Flutter and Firebase. Users can sign in, create notes with title and content, view them as color-coded cards, and search through their entries. Designed with a warm brown/beige color palette and owl mascot branding.
